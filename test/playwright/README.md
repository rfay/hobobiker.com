# hobobiker.com migration tests

The definition of the site as it is today, and the tests every migration target must pass. Built with
[site-migration-kit](https://github.com/rfay/site-migration-kit), vendored in `kit/` (version in
`kit/KIT_VERSION`; never edit it here). Findings are in `../../DISCOVERIES.md`.

## Layout

| Path | What |
|---|---|
| `migration.config.mjs` | The only per-site configuration: selectors, content listing, discovery bounds |
| `scripts/generate-manifest.mjs` | Lists every node (any status, current revision, aliases + `node/N`) and every uploaded file → `data/manifest.json` |
| `scripts/export-access-baseline.mjs` | Freezes `baseline/access.json` (status of each unpublished path) and `baseline/assets.json` (size, SHA-256) |
| `baseline/` | **Frozen. Read-only once a migration starts.** Never regenerated by a transform or pipeline |
| `expected-differences.json` | Deliberate, reviewed differences per target. Empty at the freeze |
| `tests/` | Thin wrappers around the kit's tiers, plus the access, asset and sanity specs |

## Freezing the baseline (once, from the pristine original)

```bash
migration/restore-pristine.sh                                        # project root
cd test/playwright
node scripts/generate-manifest.mjs                                   # host
node kit/scripts/stored-exporters/drupal6.mjs                        # host
ddev exec -d /var/www/html/test/playwright 'node scripts/export-access-baseline.mjs'
ddev exec -d /var/www/html/test/playwright 'node kit/scripts/export-semantic-baseline.mjs'
ddev exec -d /var/www/html/test/playwright 'node kit/scripts/export-layout-baseline.mjs'
```

## Running the tiers

Always inside the container. `TEST_BASE_URL` set on the host is **not** forwarded.

```bash
T='ddev exec -d /var/www/html/test/playwright'
$T 'npx playwright test --grep "sanity:"'                  # the baseline itself (offline)
$T 'npx playwright test --grep "semantic:|access:"'        # HTTP tiers
$T 'npx playwright test --grep "asset:"'                   # every file, byte for byte
$T 'npx playwright test --grep "(visible|layout):.*@smoke"'  # browser tiers, smoke subset
$T 'TEST_BASE_URL=http://localhost:4173 MIGRATION_TARGET=static npx playwright test'   # a target
```

Stored tier (compares databases; needs an export from the target):

```bash
node kit/scripts/stored-exporters/drupal6.mjs --out tmp/stored-now.json      # host
$T 'STORED_TARGET_EXPORT=tmp/stored-now.json MIGRATION_TARGET=drupal11 npx playwright test --grep "stored:"'
```

## Retiring to static HTML (Part 2)

One command, from the host, with `hobobiker-copy`, `hobobiker-prep` and `hobobiker-static` running:

```bash
retire/run.sh               # restore prep, prepare, crawl, rewrite, every tier (about 7 minutes)
HTTP_ONLY=1 retire/run.sh   # skip the browser tiers
```

It never touches this site: it restores and prepares `hobobiker-prep` (`retire/prep/`, one script per
change, each printing a count), crawls it into `hobobiker-static/public`, and checks that with
`MIGRATION_TARGET=static`. The static target's deliberate differences are the `"target": "static"` entries
in `expected-differences.json`. Results and decisions: "Part 2" in `../../DISCOVERIES.md`.

Tags: `@smoke`, `@<type>` (`@blog`, `@triplog`, `@route`...), `@tripinfo`, `@hobophoto`, `@php`, `@flash`,
`@script`, `@iframe`, `@empty-body`, `@has-comments`, `@draft`, `@assets`.
